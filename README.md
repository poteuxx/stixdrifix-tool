# Stixdrifix-tool | SolutionsTechnologies

A premium, all-in-one controller management suite designed for high-precision gaming and stick drift elimination.

## 🚀 Features

- **Drift Fixer Pro**: Advanced axial deadzone calibration to eliminate stick drift on any controller (USB-optimized).
- **Macro Runner**: Record and execute complex input sequences. Built-in empathy for .gmk (TitanTwo) style macros.
- **Turbo Mode**: Rapid-fire emulation with customizable frequencies (1Hz - 30Hz).
- **Universal Remapper**: Software-level remapping of controller inputs to other controller buttons or keyboard keys.
- **Live Input Engine**: Real-time visual feedback using high-frequency polling.

## 🎨 Design Philosophy (SolutionsTechnologies)

- **Glassmorphism**: Elegant semi-transparent UI elements with backdrop filtering.
- **Neon Branding**: Inspired by the ST-AI design language with gradients and subtle glows.
- **Dynamic UX**: Smooth transitions between modules and interactive stick visualizations.

## 🛠️ Usage

1. Open `frontend/index.html` in a modern browser.
2. Connect your controller via USB.
3. Select the **Drift Fixer** tab to calibrate your stick deadzones.
4. Use the **Dashboard** for live input monitoring.
